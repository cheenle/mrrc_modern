# v1.7.8 Stable Website Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish the verified v1.7.8 Windows x64 installer and synchronized bilingual documentation at `https://www.vlsc.net/mrrc_ft710/`.

**Architecture:** Keep the existing static-site structure and evergreen download URL, add a versioned download beside it, and rebuild generated SDD HTML from the Markdown source. Installer binaries remain ignored deployment inputs rather than Git objects; tracked HTML, Markdown, build metadata, and deployment checks carry the release record.

**Tech Stack:** Static HTML/CSS, Markdown, Python SDD builder with pandoc, Bash deployment over SSH/nginx, Git, curl, SHA-256.
