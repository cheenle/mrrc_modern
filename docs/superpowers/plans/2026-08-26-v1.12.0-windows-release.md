# v1.12.0 Windows Stable 发布实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 将已验证的 IC-7300/IC-7300MK2 CI-V 加固发布为 MRRC Modern v1.12.0 Stable Windows x64 安装包，并完成源码、网站、文档和 Git 标签发布。

**架构：** 沿用现有 Windows 11 KVM 上的 PyInstaller 三目标 + Inno Setup 构建链。先提交并推送构建所需的 1.12.0 版本元数据，再以干净源码构建；只有拿到真实字节数和 SHA-256 后才提交网站与文档元数据，部署后下载两份线上产物复核，最后创建标签。

**技术栈：** Python 3.12、unittest、PowerShell 5.1、PyInstaller 6.21.0、Inno Setup 6.7.3、SSH/SCP、静态 HTML、nginx、Git。

**SDD 追溯：** 保持 AD-010 与 UC-007 的天调持久化边界，不修改 `atr1000_tuner.json` 或 `mem_channels.json`；不把本次发布描述为已解决 I7，并维持 SC9 的既有声明范围。
