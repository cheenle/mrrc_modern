# 中兴云电脑 W152D 能不能刷成我们的盒子？—— 结论与代价

**一句话**：**不能直接刷**。我们的镜像是给 **Amlogic S905L3A（G12A 家族）+ W103D 的板级 dtb** 编的，W152D 是 **S905L4（GXL 家族，社区称与 S905L3S 同档，dtb 代号 `glxl4`）** —— 换的是芯片家族，不是换个型号。要它跑我们这套，等于做一次**新板型适配**；而"用安卓当服务端"那条路，代价比刷机更大，且会丢掉我们现在整套运维设施。

标注沿用仓内惯例：**fact** / **inference** / **未验证**。

---

## 一　这台机器到底是什么

| 项 | 值 | 来源 |
| --- | --- | --- |
| SoC | **Amlogic S905L4**（四核 A53，Mali-450） | 拆机与商家资料一致；社区称"S905L4 与 S905L3S 配置一样" |
| 内存 / 存储 | **2 GB / 64 GB** | 同上 |
| 系统 | **Android 11**（中国移动云电脑定制，需企业账号激活，否则半砖） | 开 ADB 教程与开箱文 |
| 网络 | **百兆网口** + Wi-Fi + 蓝牙 | 同上 |
| USB | 3× USB2.0 + **1× USB3.0** + Type-C（5 V/3 A 供电） | 同上 |
| 视频 | HDMI 输出 1 路 + HDMI 输入 1 路（显示器可单独当显示器用） | 同上 |
| 代工/批次 | 广西三创；**后续批次有"高安锁"**（SecureBoot 层硬化，只能去运营商锁、装第三方 APK，**刷不了新系统**） | 开箱文明确点出这个坑 |

对照我们现在的盒子：W103D 是 **S905L3A（G12A）**、2 GB 内存、8 GB eMMC、百兆网口、MT7663S Wi-Fi（只 2.4 GHz）。

**结论**：CPU 档位同级（都是四核 A53），内存一样，W152D 多的是 **存储（64 GB）与一个 USB3 口** —— 这两样都不是我们的瓶颈（服务端常驻约 300–500 MB，录音写盘 ~29 MB/小时）。

---

## 二　为什么不能直接刷我们的镜像

1. **芯片家族不同**（fact）。我们镜像是 ophub 的 `meson-g12a` 家族 + **`meson-g12a-w103d.dtb`**；`armbian-install` 里板型 ID 钉死 **307 = ZTE-W103D**（`docs/W103D_GUIDE.md` §17）。S905L4 的 dtb 代号是 `glxl4`（GXL），**G12A 的内核/dtb 在它上面起不来**。
2. **目前没有 `glxl4` 的可用 dtb**（fact，2025-12 的社区帖；本次检索到 2026-08 也没有发布）。GXL 家族里有 S905L3B/S905L3S 的 dtb，但**没有人验证过 S905L4 的 PHY、eMMC、Wi-Fi、USB 组合**。
3. **可能有高安锁**（fact，见上表）。这一类机器连"刷个第三方安卓"都做不到，只能去运营商桌面 —— 我们的镜像更无从谈起。**买之前必须问清批次**。
4. **Wi-Fi 是未知数**（未验证）。W103D 的 Wi-Fi 依赖**专属内核补丁 + 固件 overlay**（`packaging/box/README.md` 明确写：换通用内核 = 静默丢 Wi-Fi）。W152D 的 Wi-Fi 芯片型号未知，能不能用只能上机试。
   好消息：**我们默认走有线**（百兆够用：频谱 51 KB/s + Opus 64 kbps + CAT）。Wi-Fi 只影响「盒子设置 → Wi-Fi」那一页。

## 三　要它变成我们的盒子，实际要做的四件事

这是一次**新板型适配**，和当初做 W103D 是同一类工程（我们那份适配的记录在 `docs/W103D_GUIDE.md` §17–§18）：

1. **找到或做出 `glxl4` 的 dtb**：先试 GXL 家族里 S905L3S/L3B 的 dtb，逐一验证 —— 网口 PHY（百兆能不能通）、eMMC（能不能认到 64 GB）、USB（USB3 口 + 三个 USB2 口）、红外/电源键。**这一步不通，后面都不用谈。**
2. **U 盘试跑**：我们的镜像写 U 盘 → 插上开机 → 能起来才有戏（`docs/W103D_GUIDE.md` §5 的流程）。刷 eMMC 之前一律 U 盘启动试。
3. **服务层验收**：`mrrc-service-layer.sh` 那套（systemd 单元、venv、日志轮转、`mrrc-update`、frpc、11 份机型 profile）+ 真机导入检查（`tests/test_image_imports.py`）。
4. **电台端到端**：CAT（38400/115200）、USB 声卡 44.1 kHz、PTT 释放、频谱（FTX-1 没有真频谱，走 S 表合成，所以这台机器上反而没有 FT4222 那一堆坑）。

**成本估计**（inference）：dtb 摸索 1–3 天（有现成 GXL dtb 可试的情况下），服务层接线半天，真机验收 1 天；**前提是这台机器不是高安锁、且 dtb 能摸出来**。

## 四　"用安卓当软件后端"这条路为什么更贵

我们的服务端不是一个纯计算的程序，它把 Linux 系统当成平台用（`server.py` 直接读这些）：

| 服务端要什么 | Android 给什么 |
| --- | --- |
| `/dev/ttyUSB*` 打开 CAT 串口（pyserial） | 应用层看不到这些节点（SELinux）；**root 也未必有 cp210x 内核驱动** |
| `pyaudio`/ALSA 直接开 USB 声卡的 44.1 kHz 采集与播放 | 声卡被 AudioFlinger 独占；应用只能经 `AudioRecord`/`AudioTrack`，**Python 拿不到** |
| systemd 守护 + 开机自启 + 崩溃重启 | 没有；要靠前台服务 + WakeLock，Android 11 还会杀后台 |
| `nmcli`（Wi-Fi 页）、logrotate、`/proc`（性能页）、AF_UNIX 控制 socket（蓝牙遥控） | 都不存在，要各写一套 |
| `mrrc-update` 一键升级、诊断包、支持流水线 | 全部作废 |

所以"安卓做后端"的真实形态是：**再写一个安卓原生的服务端**（Kotlin：USB Host API 驱动 CP210x + `AudioRecord`/`AudioTrack.setPreferredDevice` 路由 USB 声卡 + Opus/WebSocket + 自己的一套界面与更新）。技术上不是不可能 —— `usb-serial-for-android` 能跑 CP210x，Android 12+ 也能给播放/采集指定 USB 设备 —— 但那是**第二套产品**，不是"换个思路"。

真正划算的"安卓思路"只有一条：**让 W152D 当客户端**（装我们的 APK 或开网页），服务端留在 W103D 或任何一台 Linux 上。这样今天就能用，零适配。

## 五　决策表

| 你的目标 | 该选哪条 | 代价 |
| --- | --- | --- |
| 现在就要一台能用的盒子 | **继续用 W103D**（或买已适配的 S905L3A 机型） | 0 |
| 想要更多存储 / 更快写盘 | W152D 不值：64 GB 换个 8 GB 省不下什么，录音按小时算也就几十 MB | — |
| 手上已经有一台 W152D，想让它干活 | 先确认**不是高安锁** → U 盘起 GXL dtb 试 → 起得来再做服务层 | 1–3 天摸索 + 真机验收 |
| 想"保留安卓、在这台机器上跑服务端" | 不建议：等于第二个产品；只在"必须安卓"的场合（比如运营商强制）才有意义 | 数周起 |
| 想让 W152D 当显示端/遥控端 | 装 APK 或浏览器，指向已有服务端 | 0 |

## 六　下单/上机前必须问清的六件事

1. **是不是高安锁批次？** 卖家能不能给"已刷第三方系统"的机器（能刷就说明没锁）。
2. **拆机确认丝印**是不是 S905L4（别把 W132D / W103D 混进来：W152D 是白色，W132D 是银色）。
3. **Wi-Fi/蓝牙芯片型号**（只影响 Wi-Fi 页与蓝牙遥控，不影响有线主功能）。
4. **USB3 口带不带电、能不能同时带 USB 声卡 + CAT**（我们的电台是一根 USB 线两件事）。
5. **网口是不是真百兆**（不是 USB 转的）。
6. **电源**：Type-C 5 V/3 A —— 与我们现在的 DC 电源不通用，发货清单要写清。

---

## 七　结论

- **刷我们的镜像**：不能直接刷；要做一次 **GXL/`glxl4` 板型适配**，且**必须**先排除高安锁。适配成功后它与 W103D 同级（CPU/RAM 相同），多的只是存储与 USB3。
- **安卓当后端**：不划算（第二套产品，且丢掉 systemd/升级/诊断/遥控那一整套）。
- **最省事的路**：W152D 只能当客户端；盒子继续用 **S905L3A**（W103D 或其同族）。

如果要往"适配 W152D"推进，第一步不是买机器，是**拿一台能刷的机器把 `glxl4` 的 dtb 摸出来**（U 盘起 GXL 家族镜像 + 改 `/boot/uEnv.txt` 的 FDT），这一步的结论决定后面所有事。
