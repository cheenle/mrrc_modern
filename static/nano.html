读取中…

升级会整片擦除 flash：标定槽与设置全部清空， 升级后要在设备上重做 OPEN/SHORT/LOAD 标定；行为异常就 CONFIG → RESET AND CLEAR。 变体别猜：看机器标签，硬件版本以 MS / SI / ZK 结尾（官方 1.2.43 说明）。

不放心网页升级？手动路径（Mac + dfu-util，官方标准流程）

① 按标签定变体，下载对应 .bin（上面的目标版本选的就是官方 release）；
② 把 NanoVNA 插到 Mac，进 DFU：设备菜单 CONFIG 里有 DFU 项，或终端 printf 'reset dfu\r' > /dev/cu.usbmodem*（屏幕会提示 DFU 模式）；
③ brew install dfu-util（如果没有），然后 dfu-util -a 0 -s 0x08000000:leave -D NanoVNA-H4-MS_20260516.bin；
④ 刷完拔插一次，开机看 info 的版本号；SI/MS 选错可在 CONFIG → EXPERT SETTINGS → MORE → MODE 里切换，只有 ZK 是真硬件区别；
⑤ 重做标定（设备上 CONFIG → CALIBRATE）。网页路径与这条用的是同一个 ROM bootloader， 刷坏只会停在 DFU，再刷一次即恢复。
