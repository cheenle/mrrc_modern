盒子连不上外网？在你的 Windows 电脑上双击修好

盒子在你家局域网里打得开网页，但上不了外网：软件更新一直转、 公网入口打不开、诊断包传不上去。用这一页的工具，五分钟内能在你自己的电脑上修好 —— 全程只用鼠标和键盘输入，不需要懂 Linux，也不需要密码之外的任何东西。

你怎么判断是这个问题

不用敲任何命令，看这三条就够了（中一条就往下走）：

  • 用浏览器打开 https://盒子IP:8888 —— 正常；
  • 页面里 ☰ →「软件更新」点「检查更新」—— 一直转圈，最后报失败；
  • 家里其它设备上网正常（手机、电脑都能看视频）。

换句话说：盒子能连上你，却连不上外面。原因通常是它记着一个不属于你家的 DNS 地址 —— 你在页面上看不到它，也不用去找它。

先准备两样东西

  1. 盒子的 IP 地址 —— 就是你浏览器地址栏里那个，例如 192.168.1.50。
  2. 盒子的网页登录口令 —— 你平时打开盒子页面输入的那个。 不是 SSH 的、也不是 Wi-Fi 的。

下载

  MRRC-FixDNS.cmd

约 9 KB，单个文件，不用安装。放在桌面或下载文件夹， 双击运行即可。它不往任何地方上传东西，也不会改你的路由器。

系统要求：Windows 10（1809 及以上）或 Windows 11。用的都是系统自带的 curl.exe 与 PowerShell，不需要额外装任何软件。

三步

  1. 双击 MRRC-FixDNS.cmd。会弹出一个黑色的窗口，这是正常的。
  2. 提示 Box IP address… 时，输入盒子的 IP（例如 192.168.1.50），回车。
  3. 提示 Web password… 时，输入网页登录口令，回车。 输入时屏幕上不显示字符，这是正常的。

然后它会自己做完全部事情，并把过程打印出来。

怎么算修好了

窗口里会出现两段结果。第二段如果写着 already a symlink（意思：现在已经是正确状态了），就是修好了： 

--- running it once more: it must be a no-op now ---
fix_resolv_conf: /etc/resolv.conf is already a symlink — nothing to do
fix_resolv_conf: done

最后一行会显示 DONE - the box now resolves through systemd-resolved.。 按任意键关掉窗口，然后回浏览器：

  • ☰ →「软件更新」→「检查更新」应该几秒内有结果（不再转圈）；
  • 公网入口 你的呼号.mrrc.vlsc.net 能打开了；
  • 「🐞 遇到问题」里的诊断包能传上去了。
这些都没好转？说明不是同一个问题。把那几行字截图，连同盒子的型号与版本 （页面 ☰ 菜单底部有）一起发给我们。

窗口里报错了怎么办

窗口上写着 意思 / 你该做什么
No answer from 192.168… 这个地址连不上盒子。回到浏览器确认地址栏里的 IP 是否一样，或换个浏览器再试。
Login refused / Invalid password 网页登录口令不对（区分大小写）。如果是「只读/旁听」口令，也不行 —— 要用管理口令。
This box predates the repair（或提示 404） 这台盒子的固件比这个工具早，工具还没法替它修。 把这一句截图发给卖家/维护者，他们那边有办法，你不需要自己做什么。
could not ... systemd-resolved / 提示没有 systemd-resolved 这台盒子的系统不是我们发的镜像（或被人改过），工具故意没有动它。把这句发给卖家。
窗口一闪就没了 右键这个文件 →「以管理员身份运行」再试一次。

它到底做了什么（不用看懂也能用）

你的电脑只是通知盒子：让它把自己记错的那个"外网地址簿"换回正确的。 真正的修复是盒子自己做的，而且可以反悔：旧文件被备份保留， 卖家随时能还原。整个过程不传出你的口令、不上传任何文件、不改路由器设置。
