在 Windows 上做一张 W103D 刷机盘

从下载镜像到盒子能开机 —— 中间只有 4 个判据要盯，其余都是等待。

本页路线
  1. 做盘（一个文件，双击）
  2. 让盒子从这张盘启动（复位孔）
  3. 固化进 eMMC（armbian-install）
  4. 断电前四项验收
  5. 出厂口令与常见问题

这条路是给谁的

W103D（及同家族的 W102D / W105D）出厂时系统已经在 eMMC 里，插电就能用。 会走这一页的只有两种人：

  • 要把一台盒子从头刷一遍（换版本、救砖、批量代刷）；
  • 想自己攒一张克隆盘，以后一台一台刷 —— 盘上是什么，盒子就是什么。

盒子已经能用、只是想升级版本？不用刷盘：打开盒子页面 → ☰ → 设置 →「软件更新」。见盒子用户指南。

你需要

U 盘 ≥ 8 GB（镜像解开 3.43 GiB；标称 4 GB 的盘实际常只有 3.6 GiB，别赌）。 盘上原有的东西会全部消失。
电脑 Windows 10（1809 及以上）或 Windows 11，管理员权限（写裸盘必须）。
盒子 W103D / W102D / W105D 任一，原装电源。
回形针 按复位孔用 —— 它在 AV 孔里面，不是外壳上的独立按钮。
HDMI + 显示器 不是必须，但没有它只能靠猜。有的话一眼看出进没进 update 模式。

第一步：做盘（一个文件，双击）

  MRRC-W103D-Flash.cmd

放到桌面，双击。它会自己请求管理员权限（UAC 点「是」）。第一次运行会从本站下载 1.2 GB 的镜像 —— 网络断了重跑会接着下，不会从头来。

屏幕上会依次出现这五段

== 镜像
   正在下载（约 1.2 GB，可断点续传；中断后重跑会接着下）…
   OK  下载完成：1.1 GB

== 校验哈希
   OK  SHA-256 一致：14dbf2dd…
   OK  解压后大小：3.4 GB

== 可写磁盘

  #    型号                                容量        总线/介质      状态
  ---  ---------------------------------  ----------  ------------  ----
  0    WDC WD10EZEX-08WN4A0              931.5 GB    SATA/Fixed    系统盘（禁止）
  1    SanDisk Ultra USB 3.0              28.7 GB     USB/Removable ✓ 可写
  2    Samsung SSD 980 PRO 500GB          465.8 GB    Nvme/Fixed    内置盘（禁止）

可写：#1
输入要写入的磁盘编号（其余键退出）：

这时输 1，回车。接着它要你亲手打 ERASE：

即将抹掉这一块盘上的全部数据：
   #1  SanDisk Ultra USB 3.0  28.7 GB  (USB/Removable)
确认请输入 ERASE（大小写均可，其它任何输入都会取消）：

输 ERASE 回车，开始写。写入时显示进度与速度；写完还有一段 回读校验 —— 它会把整份镜像从 U 盘读回来重新算一遍 SHA-256。

看到这一句才叫成功：
OK 回读一致：盘上这份 == 镜像那份
看不到它就别拿去刷盒子。

USB 3.0 的盘整个过程约 1–2 分钟；USB 2.0 要 5 分钟以上。

为什么它不让你选 C: 盘

这个工具只认 USB / 可移动介质。系统盘和内置硬盘不会出现在可写列表里， 也没有「我确定」的覆盖开关 —— 那不是没做完，是刻意这么写的：弄错一次的代价是整台电脑。

反过来也有代价：有些读卡器会把 SD 卡报成「固定盘」，那就不会出现在列表里。 换一个读卡器，或走手工路线（Rufus / balenaEtcher）。

第二步：让盒子从这张盘启动

  1. 盒子断电（拔电源）。
  2. 先插 U 盘，再上电 —— 顺序反了没用，u-boot 那时已经扫过一圈。
  3. 用回形针按住 AV 孔里面的复位键不放。
  4. 通电，继续按住约 10 秒，再松手。

怎么知道进没进 update 模式

接 HDMI 一眼就看出：

HDMI 上看到 含义 下一步
安卓开机动画 没进 update 模式 重来：从通电那一刻起就按住
黑屏 / u-boot 字样 进了 update，但没找到盘 换 USB 口，看 U 盘指示灯有没有闪
滚动的 Linux 内核日志 成功 等它起完（首次扩 rootfs 要几分钟）

没有 HDMI 也能验证：上电两三分钟后，路由器 DHCP 列表里多了一台 MRRC-Modern；或在同一网络的电脑上打开 https://MRRC-Modern:8888。

第三步：把系统固化进 eMMC

这一步在盒子上做（SSH 或 HDMI+键盘都行）。盘上这套系统会被整份复制进 eMMC， 之后拔掉 U 盘，盒子就从 eMMC 启动。

先确认三条前置，缺一条就别下笔：

grep -E "^MODEL_ID|^DISK_TYPE" /etc/ophub-release     # 必须 307 / usb
ls /boot/u-boot-w103d.bin /boot/dtb/amlogic/meson-g12a-w103d.dtb
lsblk -dn -o NAME,SIZE,TRAN,MODEL                      # mmcblk2 = eMMC

然后非交互安装：

nohup sh -c 'printf "307\n1\n" | /usr/sbin/armbian-install' > /root/emmc-install.log 2>&1 &

两个答案是 307（本板型）和 1（装到 eMMC）。 永远不要加 -m yes —— 那会换掉本板的 u-boot-w103d.bin。

完成判据只有一条：
grep -c "Installation completed successfully" /root/emmc-install.log 等于 1。实测约 2 分 15 秒。

别这样等：while pgrep -f armbian-install; do sleep 10; done —— pgrep -f 会匹配到你自己这条命令行，循环永不退出；现场看起来像 「装了两个小时」，日志显示两分钟就完了。

第四步：断电前四项，全绿才准拔盘

这四项把「能开机」和「开完还是好的」分开。逐条命令见 docs 里的 emmc 章节，这里给判据：

# 检查 期望
1 新分区表 p1 = BOOT_EMMC（511 MB vfat）、p2 = ROOTFS_EMMC（其余全部 ext4，新 UUID）
2 原厂引导两段 与 /usr/lib/u-boot/mybox-bootloader.img 逐字节一致
3 引导指向 uEnv.txt 里的 root=UUID= 等于新 p2 的 UUID
4 代码身份 挂上新 p2 后 version.txt 与镜像一致

四项过了 → poweroff（别直接拔电）→ 拔掉 U 盘 → 再上电。 这次应当从 eMMC 启动：findmnt -no SOURCE / 是 /dev/mmcblk2p2。

出厂口令（预置版镜像）

账号 出厂口令 在哪改
网页登录 abcd!1234 设置 →「登录口令」
root（SSH / HDMI） abcd1234 设置 →「系统账号口令」
mrrc（服务账号） abcd!1234 同上

这三条是同一批镜像共用的公开值，而且镜像默认允许 root 用口令登录 SSH。 通电第一件事就是全部改掉。

常见问题

双击后说「已保护你的电脑」 浏览器给下载的文件打了「来自 Internet」标记。点「更多信息」→「仍要运行」
列表里没有我的 U 盘 它被报成「固定盘」（多见于读卡器 + SD 卡），或容量小于镜像。 换读卡器，或走手工路线
清盘失败 / 盘被占用 关掉资源管理器窗口、杀毒软件的实时扫描、其它刷盘工具，再重跑
回读不一致 不要用这张盘刷盒子。最常见是扩容盘（标称容量是假的），其次是坏块。换一根盘
刷完 Windows 弹「需要格式化」 正常。盘里是 Linux 分区，Windows 读不懂，别点格式化
盒子还是进安卓 按住复位孔的时机不对：必须从通电那一刻起按住，且插盘要在上电之前
黑屏 / 停在 u-boot 进了 update 模式但没找到盘：换 USB 口，确认 U 盘灯有反应
盘上根分区只有 2.9 GB 镜像如此，不会自动长。系统跑起来后 growpart /dev/sda 2 + resize2fs /dev/sda2 （先 apt-get install -y cloud-guest-utils）
想先只验下载、不碰盘 MRRC-W103D-Flash.cmd -DownloadOnly

不想用这个脚本？

手工路线一样可行，只是别踩坑：

  • Windows：Rufus 或 balenaEtcher，选 .img.gz 本体 （两者都能直接吃 gz），模式是「从镜像写入」，不是解压后复制文件。
  • macOS：gzip -dc … | sudo dd of=/dev/rdiskN bs=4m —— 用 rdiskN（裸设备），diskN 慢十倍以上。
  • Linux：gzip -dc … | sudo dd of=/dev/sdX bs=4M status=progress conv=fsync

完整的手工流程（校验、扩容、预置客户 Wi-Fi）见 W103D 从零指南；刷好之后的日常使用见 盒子用户指南。

脚本源码：仓库 website/downloads/MRRC-W103D-Flash.ps1。 刷机镜像的稳定地址是 downloads/MRRC-Modern-w103d.img.gz，校验值随镜像一起发布 （.img.gz.sha256）。
