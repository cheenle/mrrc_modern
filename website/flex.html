实验性机型 · 发射默认关

FlexRadio（SmartSDR）接入

FLEX-6400 那一族没有串口 CAT、也没有 USB 声卡 —— 控制和音频都走网线。 MRRC Modern 直接把 SmartSDR 协议讲了一遍，所以盒子只吃一根网线， 地址还能留空：盒子会听电台自己的广播把它找出来。

接线一根网线，盒子和电台同一网段。不需要串口线、不需要声卡。
发射默认关。盒子设置页「实验机型的发射」勾上才发，且电台面板里必须把 PC 音频选成发射源。
前提电台自己的 TX timeout 设到 30 秒。网线掉了，那一条是最后一道防线。

1. 为什么这台机器和别的机型不一样

Yaesu / Icom 是「串口 CAT + USB 声卡 + 电台自己的频谱口」；FlexRadio 是 「一条 TCP 控制通道 + 一路 UDP 二进制流」，频谱、收听音频、发射音频全在这条流里。

面FlexRadio 的做法
控制TCP 4992 文本命令（频率、模式、增益、PTT、天调…）
频谱电台把 panadapter 的 FFT 直接推给客户端（UDP），不是我们采的
收听24 kHz 浮点立体声，我们升采样到 48 kHz 单声道再给浏览器
发射电台只收 Opus：24 kHz 立体声、10 ms 一帧。浏览器麦克风的声音由盒子编码后送出
发现电台每秒在 UDP 4992 广播自己（型号、序列号、IP）——盒子听着就行

2. 接线与电台侧的三件事

2.1 网线

盒子和电台接同一个交换机 / 路由器，同一网段。电台用 DHCP 或固定 IP 都可以 —— 地址留空时盒子靠广播发现它，不需要知道 IP。

2.2 把 PC 音频选成发射源

在电台的 P/CW 面板（或 SmartSDR 的发射设置）里，把发射音频源选成 PC / DAX 一侧的 PC 音频，不要停在麦克风。做不到这一步，按下发射键 电台会发一个没有声音的载波 —— 我们的软件会在按键后 1 秒内发现这件事并 自己放开按键（见 §4），但根因在电台面板上。

2.3 TX timeout 设到 30 秒

正常放手、关浏览器、心跳丢失，盒子都会主动放开 PTT。但网线被拔掉时盒子什么都发不出去 —— 那一秒只有电台自己的超时能救场。菜单里的 TX timeout 建议 ≤ 30 秒； 盒子发现它超过 60 秒时会在启动日志里点名，自检脚本也会把它列为红项。

3. 盒子上的设置

「连接设置」里机型选 FlexRadio (SmartSDR)：

  • 电台 IP 留空（默认）→ 自动发现。同一网段有多台时，填上想连的那台的 IP。
  • 不需要选串口，也不需要选声卡 —— 这两栏对这一族不显示。
  • 盒子重启后自动重连：先 1 秒、再 2/4/8 秒，最长 30 秒一次。

5. 发射：门禁与"静音载波"自证

这一族还没有真机验收，所以发射默认是关的（和 G7250、FTX-1F 同一条规矩）。 开启方式：设置 → 实验机型的发射（勾选并确认），立即生效，不用重启。

解锁之后仍然有两道检查：

  1. 按键要真的通电：盒子发 xmit 1 后 1.5 秒内，电台的收发状态机 必须进入「正在发射」，否则盒子自己取消按键并报错 —— 不会让你以为发了。
  2. 声音要真的进去：按键后 1 秒内，电台自己的 MIC 电平表 （SC_MIC）必须看到能量。没有能量而盒子明明在送音频，就立刻放开按键并 锁住后续发射，同时在日志和界面里说「去电台面板把 PC 音频选成发射源」。 这是刻意的：宁可拒绝发射，也不发一个静音载波。

解锁后想再关掉，取消勾选即可（关闭不需要确认）。

6. 上线前先跑自检

盒子上（或能 SSH 进去的机器上）：

python _diag_flex.py                  # 自动发现，只读
python _diag_flex.py --host 192.168.1.50
python _diag_flex.py --tx-check --allow-tx   # 假负载上发 200 ms 载波

报告里该看什么：

  • 机型 / 序列号 / 固件 —— info 通了才说明协议对得上
  • FFT 帧数 > 0，且 UI 字节的 min/mean/max 不是全 0 也不是全 255
  • 音频包数 > 0；表清单里能看到 SLC LEVEL 与 TX- FWDPWR
  • TX timeout 那一行：超过 60 秒是红项

脚本默认只读，结束时会删掉自己建的 pan 与音频流、并释放 PTT。加 --tx-check --allow-tx 才会发 200 ms 载波。

7. 排障

症状先看这里
连不上，日志说没发现是否同网段；交换机是否隔离广播；同网段多台时手动填 IP
连上了但没瀑布电台是否已有两个 panadapter（6400 上限 2）；UDP 是否被防火墙拦
有瀑布没声音电台音量与静音；盒子是否在「只听」角色；浏览器音量
按了发射没反应发射门禁没解锁，或被 §5 的静音载波自证锁住了
发射是"哑载波"电台面板里 PC 音频不是发射源（§2.2）
拔网线后电台一直在发电台 TX timeout 太长（§2.3）—— 这是唯一能在断网时放开 PTT 的东西

8. 适用型号与已知未验项

同一份协议覆盖 6000 族（FLEX-6300 / 6400 / 6400M / 6500 / 6600 / 6600M / 6700）与现行 Signature 族（8400 / 8400M / 8600 / 8600M）。机型、序列号、ATU 有无都由电台自述， 代码里没有按型号分支。6400 的 ATU 是选配 —— 没有就不显示 TUNE。

还没在真机上落锤的（验收清单在仓库设计记录 §11–§12）：PC 音频源默认值、收听音频包率、 pan 的刷新率/带宽上限、选配 ATU 的状态形状、主观音质、8400/8600 与 6000 族是否完全同构。 第一台真机到手时用 §6 那条命令跑一遍即可。
