What Changed In V2.20

Pluggable Radio Backends

backends/base.py defines the RadioBackend ABC, RadioCapabilities, and a factory selected by MRRC_RADIO_MODEL (ft710, ic7300, ic7300mk2; default ft710) — AD-016.

IC-7300 / IC-7300MK2

New backends/ic7300/: CI-V codec/controller over USB 115200 8N1 (addr 0x94, IC7300_CIV_ADDR), 0x27 475-bin scope upsampled to 850 points, 48 kHz native USB audio with no resample.

FT-710 Preserved

FT-710 implementation moved into backends/ft710/ with root compat shims — Yaesu ASCII CAT, FT4222 SPI spectrum, and the 44.1 kHz device-boundary audio bridge behave exactly as before.

Multi-Radio SDD

All core chapters (01–13, 15) generalized to the MRRC Modern / mrrc_modern scope: per-backend spectrum paths, per-backend audio sample rates, and operational differences between FT-710 and IC-7300/MK2.
