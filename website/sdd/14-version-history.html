New _diag_civ.py drives the production CivController through identity → read-only probes → scope measurement (which yields the three facts that cannot be settled offline: bin count, amplitude ceiling, segment count) → static meters including raw Vd/Id → an optional 200 ms TX check with PTT read-back and manual recovery steps, then restores state and writes a paste-ready Markdown report naming civ_profiles.py as the correction target. Design Baseline Notes

  • Radios: Yaesu FT-710 and Icom IC-7300 / IC-7300MK2 superheterodyne transceivers (not SDRs). Backend selected by MRRC_RADIO_MODEL.
  • Radio Protocols: Direct serial CAT (FT-710) or CI-V (IC-7300/MK2) via pyserial — no Hamlib, no rigctld, no TCI.
  • Scope: FT-710 uses FTDI FT4222 SPI chip for 850-point FFT data; IC-7300/MK2 uses CI-V 0x27 frames on the same serial port. Both fall back to synthetic S-meter Gaussian spectrum when unavailable.
  • Audio: Bidirectional through the selected radio’s built-in USB audio interface via PyAudio. FT-710: 44.1kHz native device rate; IC-7300/MK2: 48kHz native. Opus codec (RX 64kbps, TX 64kbps CBR, both 48kHz) with Int16 PCM fallback. audio_resample.py bridges the 48kHz codec domain ↔︎ 44.1kHz device domain for the FT-710 only (960↔︎882 frame-aligned).
  • Auth: Shared-password session auth (ft710_auth cookie, 30-day, ?token= on WebSocket).
  • PTT Safety: Client-side PTT watchdog (500ms) + dead-man switch (WS disconnect) + pagehide handler + server-side TX status poll (0.5s). No TX0 verify loop on release (radio obeys TX0 fire-and-forget). TX audio drain=50ms. TUNE is press-and-hold.
  • Polling: 7-task adaptive scheduler: IF 0.1s (FA/MD0/SM0), VFO 0.5s (VS/FB), TX status 0.5s, TX meters 0.5s (RM3/4/5/6, TX only), settings 2s, slow 5s, connection watchdog 1s. Poll queries use 0.25s timeout and cooperate with priority-command preemption (_cancel_polls). Poll loops re-check skip state AFTER each in-flight query response and discard stale reads; filter sets are verified by a 150 ms SH0; read-back. After a successful watchdog reconnect the scheduler re-runs the scope-init CAT sequence (EX040101/EX040200) via its on_reconnected hook — a USB re-enumeration resets the radio’s scope output.
  • Meters: RM3-8 raw 0-255 values calibrated via piecewise-linear tables from FT-710.rig (Power/SWR/Vd/Id). Frontend displays watts, SWR ratio, volts, amps — not raw numbers.
