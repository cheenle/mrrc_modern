用 SSH 就地升级盒子（不刷机）

适用：1.27 及更早的盒子 —— 那些版本的设置页里没有「软件更新」， 也没有远程升级接口。它们的程序就是 /opt/mrrc_modern 这一棵源码树， 换掉它、重启服务即可，不需要重刷镜像，也不会动你的配置和录音。

为什么不直接用盒子上那个 mrrc-update

盒子上确实自带一个 mrrc-update，它做的也是同一件事。但 1.25.5 及更早镜像里那份用 rsync --delete 同步 —— 会把 env/（配置）、profiles/ 和录音 一起删掉。所以这个工具自带一份安装器（mrrc-remote-update.sh）： 先备份，再覆盖，一个文件都不删。

现在有两条升级路，别走错：1.28.2 及以后用页面上的 ☰ →「软件更新」，或者 远程升级指南； 1.27 及更早用这一页。

下载

  MRRC-Update-SSH.cmd

约 10 KB，单个文件。它会在你的电脑上下载官方发布包（约 19 MB），核对 SHA-256， 再推给盒子 —— 盒子本身不需要能出网去下载（但装完要能装 Python 依赖，所以盒子还是得能连软件源）。

系统要求：Windows 10（1809 及以上）/ Windows 11，并且装了 OpenSSH 客户端（设置 → 应用 → 可选功能 → 添加功能 → OpenSSH 客户端）。 盒子上要能 SSH 登录：设置页「系统账号口令」可以给 root 设新口令， 不校验旧口令。

三步

  1. 双击，输入盒子的 IP（浏览器地址栏那个），确认屏幕上写的目标版本；
  2. 输入 YES 继续 —— 它开始下载并核对发布包；
  3. 输入 SSH 账号（root 或 mrrc），按提示输入该账号的口令。 接下来它会把两个文件拷到盒子、在盒子上执行安装器。

它在盒子上到底做了什么

  1. 解包到 /tmp，确认里面是一棵 MRRC 树并且带 version.txt （没有版本号的包直接拒绝）；
  2. 备份当前代码到 /opt/mrrc_modern/.local/share/MRRC-Modern/update/rollback-manual-<旧版本>-<时间>.tar.gz；
  3. 覆盖代码：只加和改，不删任何文件；下面这些目录一律不碰 —— venv、logs、recordings、.local、 env、fleet、data、ft8-slots；
  4. 装依赖：venv/bin/pip install -r requirements.txt。 这一步失败就不会重启 —— 也就是说旧代码还在内存里照常跑；
  5. 重启服务（root 用 systemctl restart mrrc-modern， 普通账号用 pkill，systemd 会把它拉起来）。

失败时怎么办

屏幕上的话 含义 怎么办
The release manifest has no box package 线上清单里没有盒子包（很罕见） 把 latest.json 发给我们，先别升
Could not download … 电脑下载发布包失败 换网络重试；盒子没收到任何东西
does not match the manifest's SHA-256 包损坏或被中间人改过 重试；仍不行就换网络。盒子没收到任何东西
Copying to the box failed SSH 账号/口令不对，或盒子没开 SSH 用设置页给 root 设新口令，再跑一次
pip failed. The service was NOT restarted 依赖装不上（盒子连不上软件源） 盒子仍是旧版本在跑；解决网络后重跑
did not answer within 3 minutes 装完了但服务没起来 用下面「回滚」把备份放回去

回滚

安装器会把备份路径打在屏幕上。要退回去，SSH 进盒子执行（把路径换成你的）： 

sudo tar -xzf /opt/mrrc_modern/.local/share/MRRC-Modern/update/rollback-manual-1.24.8-YYYYmmdd-HHMMSS.tar.gz      -C /opt/mrrc_modern
sudo chown -R mrrc:mrrc /opt/mrrc_modern
sudo systemctl restart mrrc-modern

备份里是纯代码，配置、录音、记忆频道从来不在备份里，也从来没被动过。

会 shell 的话，一条命令也行

这个工具做的就是下面这几步，自己在电脑上手工跑同样可以：

curl -LO https://www.vlsc.net/mrrc_modern/downloads/latest.json
curl -LO https://www.vlsc.net/mrrc_modern/downloads/mrrc-remote-update.sh
# 从 latest.json 的 boxLine 里取 url / sha256，下载并核对
curl -LO <boxLine.url> && shasum -a 256 mrrc-modern-src-*.tar.gz

scp mrrc-modern-src-*.tar.gz mrrc-remote-update.sh root@192.168.1.50:/tmp/
ssh root@192.168.1.50 'bash /tmp/mrrc-remote-update.sh /tmp/mrrc-modern-src-*.tar.gz /opt/mrrc_modern mrrc'

这个工具不会做什么

  • 不重刷镜像、不改引导、不碰 U 盘
  • 不删除任何文件（这是它和盒子上那份老 mrrc-update 的唯一区别，也是它存在的理由）
  • 不动配置、录音、记忆频道、隧道与证书
  • 不需要网页口令 —— 它压根不登盒子上的 API
  • 不会自己找盒子，也不会自动升级

脚本源码：仓库 dev_tools/mrrc-update-ssh.cmd 与 dev_tools/mrrc-remote-update.sh。两者都不是安装包的一部分， 随时可以更新，改完在 答复页 说明。
