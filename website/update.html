从 Windows 电脑远程升级盒子

适用：盒子在局域网里打得开网页，但你想在自己电脑上一条命令升完， 并且当场看到结果是「升上去了」还是「被回滚了」—— 而不是隔着电话教对方去点页面。

先确认两件事

一、盒子要能上网。 升级包是盒子自己去更新通道下载的，所以这一步的前提是盒子出得去。 这和局域网取包正好相反 —— 那个工具用在盒子出不去的时候，这个工具用在盒子能出去、只是你不想跑去现场的时候。

二、盒子的版本要够新。 远程升级接口是 2026-10-18 才进主线的（盒子线从 1.28.2 起的镜像才有）。1.27 及更早 —— 包括 1.24.x —— 没有它， 这个脚本会在确认之前就停下并告诉你。那种盒子怎么升，见下面 1.24 或更早的盒子。

如果你就坐在盒子旁边、或者能打开它的页面： ☰ →「软件更新」点一下更简单。这个脚本只是把同一件事搬到你的电脑上做， 它调用的就是那个按钮背后的接口。

下载

  MRRC-Update.cmd

约 14 KB，单个文件，不用安装。放在桌面， 双击运行即可。它只对盒子说四句话：登录、问版本、开始升级、看进度， 不往任何地方上传东西。

系统要求：Windows 10（1809 及以上）或 Windows 11。脚本用的是系统自带的 curl.exe 与 PowerShell，不需要额外装软件。

三步

  1. 双击 MRRC-Update.cmd，按提示输入两样东西：
    • 盒子的 IP —— 就是浏览器地址栏里那个，例如 192.168.1.50（也可以试 mrrc.local）
    • 网页登录口令 —— 你平时打开盒子页面用的那个
    屏幕上随即打出盒子的版本、线上的版本、包多大、这一版改了什么。
  2. 看清「当前 → 线上」两个版本号，确认要升，输入 YES 回车。输入别的内容就等于放弃，什么都不会变。
  3. 等它跑完。脚本每 4 秒问一次进度，中间盒子会重启一次（断线约 10 秒）， 然后它会自己等盒子回来、重新读版本，最后告诉你结果。

FP1 是修复包编号，和版本号并排显示、不参与版本比较 —— 它回答「这是第几次修复」，版本号回答「谁比谁新」。没有修复包的版本不显示这一段。

升级期间会发生什么

  • 盒子上的服务重启一次，页面断线约 10 秒，之后自动恢复（刷新一下即可）。
  • 发射中不能升级：PTT、调谐、CQ 呼叫、FT8 发波都算。这不是脚本拦的， 是盒子自己拦的 —— 重启会掐断正在发的那一波。
  • 磁盘剩余不足 400 MB 时同样被拒绝（先删一些旧录音）。
  • 失败了会自己退回去：新版本 90 秒内起不来，盒子把上一版翻回来并重启。 脚本会明确告诉你「它回到了 X，不是 Y」，而不是笼统的一句失败。
  • 你的配置一个都不动：口令、Wi-Fi、呼号、录音、记忆频道、天调学习库都保留。

1.24 或更早的盒子能升吗？

能，但要换个装法。 那些版本里没有远程升级接口（设置页连「软件更新」这张卡都没有）， 所以脚本问完版本会让你确认「改用 SSH 直接把新程序装进 /opt/mrrc_modern」。 那不是刷机：换的是目录里的程序，配置、录音、记忆频道、隧道都不动。

为什么不能直接用盒子上自带的 mrrc-update：1.25.5 及更早 镜像里那份用 rsync --delete 同步，会把 env/、 profiles/ 和录音一起删掉。所以这个脚本自带一份安装器 （mrrc-remote-update.sh）：先备份当前代码，再覆盖，一个文件都不删， 最后重启服务。

怎么走：

  1. 照常输入盒子 IP 和网页口令，它会告诉你「这台没有远程升级器」；
  2. 输入 SSH 继续 —— 它会在你的电脑上下载官方发布包并核对 SHA-256；
  3. 输入盒子的 SSH 账号（root 或 mrrc），按提示输入该账号的口令；
  4. 等它装完 —— 盒子的服务会重启一次，脚本随后读回版本告诉你结果。
SSH 账号要先能登录：盒子的「设置 → 系统账号口令」可以给 root 设新口令 （不校验旧口令）。它和网页登录口令是两回事。

打开「用 SSH 就地升级盒子」指南 →

不想用 SSH，或者那个账号进不去：刷镜像永远可行，而且不碰数据。 这也是唯一在盒子连网页都打不开时还有效的办法。

被拒绝或者失败时

屏幕上的话 含义 怎么办
The box refused…电台正在发射 正在发波（含 TUNE、CQ、FT8） 等这一轮结束，再跑一次
The box refused…磁盘剩余不足 剩余空间不足 400 MB 删一些旧录音（☰ → 录音）后再跑
Already up to date 已经是最新版本 不用管
came back on X, not Y 升级过，但新版本没起来，已自动回滚 盒子能用了；把 mrrc-update-<电脑名> 文件夹发给我们
This box has no remote updater 盒子版本太旧（2026-10-18 之前 / 1.27 及更早），没有这个接口 刷镜像，或按上面老盒子那一节走 SSH
did not answer within 4 minutes 重启后盒子没回来 看电源和网线；它自己会在 90 秒内回滚
Login failed 网页口令不对 就是你打开页面时输的那个口令，注意别和 SSH 的系统口令搞混

每次运行都会在脚本旁边留下一个 mrrc-update-<你的电脑名>\，里面是版本、状态和盒子的原始应答。 出问题时把这个文件夹发给我们，比截图有用。

这个工具不会做什么

  • 不上传任何东西 —— 文件只落在你自己的电脑上，发不发由你决定
  • 不绕过发射门禁 —— 发射中就是不能升，这是它有意保留的
  • 不保存口令 —— 口令只进一份系统临时文件，跑完就删
  • 不改盒子上的任何配置 —— 它只点那个「升级」按钮背后的接口
  • 不会自己找盒子、也不会自动升级 —— 每次都要你输入 IP 和 YES

还是升不上去？

先在 答复页 搜索屏幕上那句话； 如果盒子连网页都打不开了，那是另一类问题 —— 用 局域网取包 把诊断包拿出来，再发给我们。
