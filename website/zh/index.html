功能特性

完整的多电台远程控制

真实频谱（FT4222 SPI 或 CI-V）、双向 Opus 音频、全功能 CAT/CI-V 控制与多层 PTT 安全——FT-710、IC-7300 与 IC-7300MK2 可插拔后端， 全链路零中间件。

真实频谱 — FT4222 SPI 与 CI-V

FT-710：约 21 fps 的 850 点 FFT 频谱，直接读自 DSP 芯片的 FT4222 SPI 接口。IC-7300/MK2：CI-V 0x27 475 点 频谱升采样到 850 点。发射感知暂停保持频谱干净，无硬件路径时 自动回退到 S 表合成频谱。

  • FT4222 SPI 直读（libft4222 + libftd2xx）
  • CI-V 0x27 频谱复用同一 USB 串口
  • 发射感知暂停——告别 PTT 后频谱错乱

FFT 频谱线 + 瀑布图

EMA 平滑的频谱折线叠加在 120 行历史瀑布之上。共享 Floor/Ceil 控制、六种色图，点击频谱任意位置直接 QSY。

  • 约 30 fps S 表回退保持瀑布不断流
  • 点击 QSY，带滚动手势拖拽保护
  • 发射时明确显示"TX 发射中 — 频谱暂停"

双向 Opus 音频

端到端统一 48 kHz 编解码域：RX 采集 → Opus 64kbps → 浏览器 AudioWorklet；浏览器麦克风 → Opus CBR → 服务器 → 电台。 FT-710 后端桥接到固定 44.1 kHz USB 音频设备域（每 20 ms 960→882 采样）；IC-7300 后端使用 48 kHz 原生 USB 音频，无需 重采样。

  • 64kbps Opus——比裸 PCM 小 12 倍
  • 零音频看门狗，声卡卡死即时告警
  • PTT 优雅释放——完整保留话音尾音

全功能 CAT / CI-V 控制

FT-710：Enhanced COM 口 38400 波特直连串口 CAT（频率、模式、 滤波、VFO A/B、分频、前置放大、衰减、NR/NB/AN、压缩器、天调、 增益）。IC-7300/MK2：USB CI-V 115200 8N1（地址 0x94），按 Icom 模式/波段/滤波表并由能力驱动的前端自适应界面。

  • 无 Hamlib / wfview / 中间件——串口直连
  • 脏字段追踪，最小化 WebSocket 流量
  • 滤波带宽设置后读回验证

自适应轮询

100ms→5s 智能间隔，0.25 秒单查询超时上限，优先级抢占保证 PTT 绝不等待轮询周期。用户命令后的在途过期读取一律丢弃。

  • 串口总占用约 296 字节/秒
  • 转 RX 时发射仪表自动清零
  • 每次串口重连后自动重发频谱初始化

仪表与记忆频道

Canvas S 表（S1–S9+60dB）带 dBm 读数，完整发射遥测： PWR / ALC / SWR / Id / Vd / COMP。记忆频道一键召回；所有界面 偏好均以 Cookie 持久化。

  • 内置初始频道，按用户存储
  • AF 音量、频谱选项、麦克风增益全部记忆

ATR1000 天调联动

可选的联网 ATR1000 天线调谐器：学习到的 LC 继电器值随每次频率 变化自动应用；服务端调谐辅助自动执行"载波—测量—保留或回滚" 全流程。

  • 默认关闭——无硬件时零影响
  • 学习门限 SWR 1.0–1.8，±5kHz 就近匹配

多层 PTT 安全

按住发射、松手即停。Fire-and-forget TX0 + 500ms 发射状态轮询 + 浏览器看门狗。最后一个客户端——或 TX 音频属主——断开时服务端 强制切回接收。

  • 7 层独立释放机制——无单点故障
  • TX 上行属主跟随实际按 PTT 的客户端
  • 断 RF 前优雅排空 TX 音频

移动优先界面

为 iPhone Safari 优化：安全区适配、PWA 清单与 Service Worker 离线缓存、Wake Lock 防息屏、全屏切换，另有原生 iOS / Android 配套应用。

  • PWA 清单 + Service Worker 离线缓存
  • Wake Lock API（屏幕常亮）
  • iOS 17+ 与 Android 原生应用共用同一协议

快速上手

五分钟跑起来

Windows 用户走安装包路线；macOS / Linux / 树莓派从源码运行。 两条路线殊途同归，都是同一个浏览器界面。

路线 A — Windows 安装包

1 · 安装驱动

FT-710：为 Enhanced COM 口安装 Silicon Labs CP210x VCP 驱动； 需要 FT4222 真频谱时再装 FTDI D2XX。IC-7300：无需额外驱动—— 单根 USB 线即带串口驱动。

设备管理器 → 端口 (COM 和 LPT) → Enhanced COM Port

2 · 运行安装包

MRRC-Modern-Setup.exe — v1.10.0，45.3 MB，x64。开始菜单 + 可选桌面快捷方式。

SHA-256 ecafb9376209fd1d91785657f2ff428576c2b660340d1d23e5f0b9d05e0080f3

3 · 编辑配置

开始菜单 → Edit Configuration——设置电台型号 （MRRC_RADIO_MODEL）、串口和强密码。

%LOCALAPPDATA%\MRRC-Modern\mrrc_modern.env

4 · 启动

开始菜单 → MRRC Modern——启动器自动拉起服务并打开浏览器。

http://127.0.0.1:8888 → 登录 → 完整控制

路线 B — 源码运行（macOS / Linux / 树莓派）

1 · 克隆仓库

从 GitHub 获取最新代码

git clone https://github.com/cheenle/mrrc_modern.git

2 · 安装依赖

Python 3.12+，FastAPI、Uvicorn、PySerial、PyAudio、NumPy

cd mrrc_modern && pip install -r requirements.txt

3 · 启动服务

选择电台型号并指定串口后启动

MRRC_RADIO_MODEL=ft710 MRRC_SERIAL_PORT=/dev/cu.usbserial-XXXX python server.py

4 · 打开浏览器

网络内任意设备——手机、平板、电脑。对外暴露前务必设置强密码。

https://服务器IP:8888 → 登录 → 完整控制
运行需求

你需要什么

八重洲 FT-710 Icom IC-7300 / IC-7300MK2 USB 线（A→B 或 C→B） Windows 安装包（内置 Python） 或源码运行 Python 3.12+ Windows / macOS / Linux / 树莓派 现代浏览器 FTDI 库（仅 FT-710 频谱）

FT-710 需要 FT4222 SPI 真实频谱时安装 libft4222 + libftd2xx（可从 wfview 应用包或 FTDI 官网获取）；IC-7300 后端直接复用 USB 串口读 频谱，无需任何 FTDI 库。CAT/CI-V 控制与音频始终无需 FTDI。

移动应用

原生 iOS 与 Android 客户端

SwiftUI（iOS 17+）与 Kotlin/Compose（Android）配套应用——与浏览器 共用同一套 4 通道 WebSocket 协议，为单手移动操作优化。

完整电台控制

频率（直接输入 / 步进 / 波段跳转）、VFO A/B、模式、滤波带宽、 前置放大/衰减、AGC、NB/NR/ANotch、射频功率、麦克风增益、 静噪——全部在 iPhone 上完成。

  • 4 路加密 WebSocket 通道（wss）
  • 令牌认证，密码存钥匙串

瀑布图 + 仪表

850 点实时瀑布配 FFT 曲线，色图与 Web 界面一致。S 表加发射 仪表（PWR / SWR / ALC / COMP）以及记忆频道列表。

  • 与浏览器相同的二进制频谱帧
  • 深琥珀主题，横竖屏皆宜

Opus 语音收发

RX：Opus 48kHz 解码并从机身扬声器播放。TX：48kHz 麦克风采集、 20ms PCM 帧——按住 PTT 即讲话。

  • libopus 真机构建（arm64）
  • 设置项：自动重连、增益、音量

早期版本——需从源码构建

需要实体 iPhone（模拟器不支持——内置 libopus 仅限 arm64 真机）、 iOS 17+、Xcode 15 + XcodeGen，以及启用 TLS 的服务端。2026-07-20 审计发现的 P0 PTT 安全问题已解决——TX 上行属主跟随实际按键的 客户端。
