V2.1 变更重点

PTT 无声故障修复

"按下 PTT 有载波但无语音/无功率" 的长时间运行软故障——根因是 TX 上行链路归属权仅在连接时分配。多客户端（浏览器标签 + iOS App 或僵尸连接）场景下 PTT 客户端的麦克风帧被静默丢弃。现在：属主断连时自动晋升 + PTT 键起时主动索取 + 每次 PTT 释放记录完整 TX 会话日志。

修复虚假"电台未连接"

频率日志守卫中的 NoneType 崩溃导致每次轮询都失败，5 次连续失败后广播 "serial_connected=false"，但实际上电台完全正常在通联。已增加 None 守卫，且成功轮询后立即恢复连接状态标志。

USB 重连后频谱冻结修复

USB 重新枚举导致电台停止发送 FFT 帧，但看门狗重连后未重新执行 scope-init CAT 指令（EX040101/EX040200），瀑布图停在旧数据上不动。PollScheduler 现在有 on_reconnected 钩子在每次成功重连后重新初始化 scope。

Web 前端安全重构

PTT 按钮改经 PTTManager 路由（此前绕过导致看门狗 + pagehide 强制关 TX 均为死代码）。TUNE 改为长按触发（原为点击锁定无确认）。键盘事件忽略重复触发和输入框内事件。修复静默渲染崩溃。服务端错误以 toast 横幅显示。
