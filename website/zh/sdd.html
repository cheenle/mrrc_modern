V2.20 变更重点

可插拔电台后端

backends/base.py 定义 RadioBackend 抽象基类、RadioCapabilities 与工厂，由 MRRC_RADIO_MODEL 选择（ft710、ic7300、ic7300mk2，默认 ft710）——AD-016。

IC-7300 / IC-7300MK2

新增 backends/ic7300/：USB CI-V 115200 8N1（地址 0x94，IC7300_CIV_ADDR）编解码/控制器，0x27 475 点频谱升采样到 850 点，48 kHz 原生 USB 音频免重采样。

FT-710 完整保留

FT-710 实现迁入 backends/ft710/ 并保留根目录兼容垫片——八重洲 ASCII CAT、FT4222 SPI 频谱与 44.1 kHz 设备域音频桥接行为与之前完全一致。

多电台 SDD

全部核心章节（01–13、15）泛化为 MRRC Modern / mrrc_modern 范围：各后端的频谱路径、各后端的音频采样率、FT-710 与 IC-7300/MK2 的运行差异。
