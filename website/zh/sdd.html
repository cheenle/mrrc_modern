V2.18 变更重点

原生 Android 客户端

新增 FT710Android/ 子项目（Kotlin + Jetpack Compose，minSdk 26）：4+1 路 WebSocket，NDK 构建 libopus，DataStore + Keystore 凭据——功能全量对齐 Web 前端（控制、RX/TX 音频、频谱、仪表、记忆频道、可选 ATR1000）。

PTT 安全原生设计

纯 Kotlin PTTManager 状态机：仅连接就绪时按下，手势 finally 释放，500ms 看门狗 + onStuckTX，生命周期 onStop 强制释放——iOS P0 竞态在设计层规避而非事后修补。

Web 界面精简

瀑布/FFT 画布紧凑化（移动端 45/22px，桌面 80/40px）；页面随内容滚动（移除固定视口）；RF Gain 滑杆从主控制区移入菜单「设置」。

Android 验证

33 个 JVM 单测全绿；./gradlew test assembleDebug lintDebug 通过；APK 内置 NDK libopus。设计文档与 19 任务计划标记完成；真机验收待用户设备。
