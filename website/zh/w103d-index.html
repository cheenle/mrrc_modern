盒子用户指南

已刷好30 分钟适合：拿到发货版盒子、插电就要用的人

三个出厂口令、连 Wi-Fi（含预置一个工作台上扫不到的网络）、接电台、五分钟验收、以及出问题时的分诊表。不需要 U 盘、显示器和键盘。

第一件事：设成自己的口令 —— 网页在「登录口令」，root / mrrc 在「系统账号口令」。

「连不上门户」，先看这一行

排障2 分钟定性适合：页面报「连不上门户」「提交失败」，或报证书、时间、隧道错的人

网络、DNS、时钟、证书、隧道 —— 任何一环出问题，页面上都是同一句「连不上」。先按判据表定位到层，再按条目处理。含无 RTC 电池的盒子为什么开机就报证书未生效。

盒子的 DNS 坏了：在 Windows 上一条命令修好

排障5 分钟适合：ping IP 通、ping 域名卡住；软件更新、公网入口、诊断包上传一起失灵的人

先给判据（resolv.conf mode: foreign + 一个不属于你的 DNS），再给 MRRC-FixDNS.cmd：只要网页登录口令，不需要 root、不需要 SSH，它让盒子自己的 root 助手跑与升级同一个修复脚本。镜像里为什么会有别人家的 DNS也写清了。

公网入口连不上时，怎么把诊断包拿出来

排障10 分钟适合：局域网打得开、公网入口打不开的人

诊断包原本只能靠「上传」，而上传要盒子能出网 —— 网络坏掉时包就出不去。这一页用一个 Windows 小工具，在你的局域网里把包直接拷回来。最后一步失败也不要紧：屏幕上那几行 tunnel_error通常已经够定位。

从 Windows 电脑远程升级盒子

升级5 分钟适合：盒子能上网、页面里有「软件更新」的人（盒子线 1.28.2 起）

用 MRRC-Update.cmd在自己的电脑上把这件事做完：登录 → 看「当前 → 线上」两个版本 → 输入 YES → 等它跑完。中间盒子会重启一次（断线约 10 秒），脚本自己等它回来并重新读版本，最后打出 Before / After / Target。

升级包是盒子自己去下载的，所以它要能出网 —— 这正好是 局域网取包的反面。

用 SSH 就地升级盒子（不刷机）

升级10 分钟适合：1.27 及更早的盒子 —— 那些版本没有远程升级接口

MRRC-Update-SSH.cmd在本机下载官方发布包、核对 SHA-256，再推给盒子执行自带安装器：先备份、只覆盖、一个文件都不删。不要直接跑那些老镜像里的 mrrc-update —— 1.25.5 及更早那份用 rsync --delete，会连带删掉配置和录音。

在 Windows 上做一张 W103D 刷机盘

刷机20 分钟 + 下载适合：Windows 用户，只需要「把镜像写进 U 盘」

一个文件双击：下载镜像（断点续传）→ 校验 SHA-256 → 选盘 → 写入 → 回读整份镜像比对。只认 USB / 可移动介质，系统盘与内置盘 没有覆盖选项。

W103D 从零指南

刷机1 小时适合：要把一台盒子从头刷到能用，或批量代刷的人

刷机盘之后的全部环节：复位孔进 update 模式（HDMI 三种画面各是什么）、armbian-install固化进 eMMC、断电前四项验收、扩容根分区、预置客户 Wi-Fi（工作台上扫不到的那种）。

遥控器指南

外设15 分钟适合：买了蓝牙遥控器、想站在电台旁边操作的人

配对、按键映射、以及那个最坑的失败模式 —— 「配上了」但按键全死：链路没加密，bluez 的 HID 设备建了就拆。

一台 ¥125 的盒子当电台服务器

长篇适合：想知道「为什么是这台」的人

从选板到踩坑的过程记录，不是操作手册。

三条常走的路线

  1. 新盒子 → 能用：用户指南 → 改三个口令 → 连 Wi-Fi → 接电台 → 五分钟验收
  2. 重刷一台：做刷机盘 → 从零指南的「让盒子从 U 盘启动」与「固化 eMMC」两节
  3. 升级：页面里有「软件更新」→ 远程升级； 1.27 及更早 → SSH 就地升级
  4. 入口打不开：局域网取包 → 把 cloud-state那几行发过来

通用前提

  • 型号：W103D / W102D / W105D是同一家族（Amlogic S905L3A），固件通用；文件名里的 "w103d" 指固件家族，不是外壳上的型号。
  • 无线只有 2.4 GHz；有线优先，音频延迟也更低。
  • 出厂口令是整批共用的公开值（网页 abcd!1234、 root abcd1234、mrrc abcd!1234）—— 通电第一件事全改掉。
